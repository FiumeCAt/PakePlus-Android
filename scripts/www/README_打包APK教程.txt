======================================================
      NovelAI 批量净图工具 Pro - 打包 APK 说明
======================================================

本工程文件夹已做好完整的移动端适配，你可以通过以下任意一种方式将其打包为安卓 .apk 安装包：

【方式一：使用 HBuilderX 云打包（电脑端最推荐，支持原生写入相册）】
1. 下载并打开免费的 HBuilderX 软件。
2. 将本压缩包解压为一个文件夹，直接拖入 HBuilderX 左侧的项目管理器。
3. 点击顶部菜单：「发行」 -> 「原生App-云打包」。
4. 勾选“Android (apk包)”与“使用公共测试证书”，点击“打包”，等待 1~2 分钟即可下载生成的 .apk 安装包！
（注：本工程已内置 window.plus 原生相册桥接代码与 manifest.json，使用 HBuilderX 打包后，点击“一键存入相册”会直接调用安卓原生接口把图片写入系统相册！）

【方式二：在安卓手机上直接打包成 APK（免电脑）】
1. 在安卓手机上下载「HopWeb」或「WebCat」或「网页转应用」App。
2. 选择“导入本地项目/ZIP”，选中本压缩包（或解压后的文件夹）。
3. 图标选择文件夹内的 icon.png，入口文件为 index.html，点击“打包 APK”即可在手机上直接生成安装包。

【方式三：使用 Website 2 APK Builder（电脑端单机免登录打包）】
1. 打开 Website 2 APK Builder 软件，选择 "Local HTML Website"。
2. Directory 选择解压后的本文件夹，App Icon 选择文件夹内的 icon.png。
3. 点击 "Generate APK" 即可立即在本地生成 APK。
